###Resources:
**Scanpy Official Tutorials:** The core `scverse` documentation, starting with the Preprocessing and Clustering 3k PBMCs tutorial.

- https://scanpy.readthedocs.io/en/stable/tutorials/index.html


**Single Cell Best Practices:** The definitive, community-driven online book for multi-omic single-cell analysis.

- sc-best-practices.org


**"Single cell analysis in python with Scanpy" (Sanbomics):** A concise 20-minute video that shows you exactly how to load an `AnnData` object, filter it, and run a basic UMAP.

- https://www.youtube.com/watch?v=5HuOGZEu2HY


**"Complete single-cell RNAseq analysis walkthrough" (Sanbomics):** A deeper, 1-hour+ dive into the entire pipeline, including normalization and clustering.

- https://www.youtube.com/watch?v=uvyG9yLuNSE
